# MJO 位相別 夏季降水量アノマリ — まとめ (ERA5 tp, JJA, 1979–2023)

対象は ERA5 daily 全降水量 (total precipitation) の **JJA 45 年** (1979–2023) コンポジット。  
気候値基準は 1991–2020、降水量はトレンド除去なし、単位は mm/day。  
RMM 振幅閾値 **≥ 1.0**（気温分析の主要ランで用いた amp05 = 0.5 より厳しい設定）。  
lags: 0, +5, +10 日。

> **注意**: 気温サマリ (`docs/summary_t2m_JJA_1994_2023.md`) は 1994–2023 の 30 年 × 振幅 ≥ 0.5 を基本とし、ENSO 層別まで実施。本ドキュメントは降水の初回解析として、全期間・全 ENSO 込み・振幅 ≥ 1.0 のみを扱う。

### 読み方のポイント

日本の JJA 日降水量の標準偏差は概ね 4–8 mm/day (気候変動込み、地域差大)。独立日仮定での SE ≈ σ/√n ≈ 5/√200 ≈ 0.35 mm/day 程度。MJO の自己相関 (~5–7 日/事象) を加味すると実効 SE はその ~2 倍で **~0.7 mm/day**。これを基準にすると:

- **Phase 8 の +1.06 °C (japan) / +2.28–2.85 (east・west)** は ~1.5–4σ レベルで最も頑健
- **Phase 4 の +0.61 / Phase 6 の −0.61** は ~1σ程度
- **Phase 3 の −0.55** も ~1σ (弱い信号)

## 3. 各位相の特徴 (JJA lag=0)

### Phase 8 — 西日本・東日本で顕著な多雨 (+2.9 / +2.3 mm/day)

**最も強い降水シグナル**。西日本 +2.85 mm/day、東日本 +2.28 mm/day、japan ボックス全体でも +1.06 mm/day。MJO Phase 8 は対流中心が東インド洋〜インド亜大陸付近にあり、西部太平洋上の水蒸気収束が活発化する段階に対応。  
沖縄でも +1.33 mm/day と正で、日本列島ほぼ全域で多雨。

北日本は +0.39 mm/day と相対的に弱い。8 パネルマップ (`fig_tp_JJA_lag+0.png`) では西日本〜東シナ海にかけて +2〜+4 mm/day の強正偏差域が広がる一方、フィリピン周辺は負偏差となるパターンが見える。

### Phase 4 — 西・東日本で多雨 (+0.4〜+0.7 mm/day)

Phase 8 に次ぐ正偏差。西日本 +0.43、東日本 +0.69 mm/day。北日本は +0.33 と弱め。沖縄は −0.24 mm/day とやや少雨側で、Phase 8 とは異なり沖縄を除く本州が主体。

### Phase 6 — 西日本で顕著な少雨 (−1.71 mm/day)

**最も強い負偏差位相**。西日本 −1.71 mm/day、東日本 −0.79 mm/day と本州南西部が少雨。japan ボックス全体では −0.61 mm/day。北日本ではほぼゼロ (−0.03)、沖縄は +0.44 と正で本州と逆符号。  
MJO Phase 6 は対流活発域が日付変更線付近にある段階で、西部太平洋の水蒸気フラックスが減少し太平洋高気圧が強化される傾向があり、本州付近への前線・水蒸気供給が抑えられると解釈できる。

### Phase 3 — 本州で少雨 (−0.55 mm/day)

気温では Phase 3 が最大の「日本暑」位相だったが、降水でも少雨 (−0.55 mm/day)。東日本 −0.76、西日本 −0.76 と本州中部・西部で明瞭。北日本は −0.13 と弱め、沖縄 −0.61 と沖縄も少雨。**「Phase 3 = 本州暑・少雨」は t2m と tp で一致した信号**。

### Phase 1 — 東日本で少雨、沖縄で多雨

東日本 −0.78 mm/day と比較的強い少雨、沖縄は +1.04 mm/day と対照的。北日本 −0.22、西日本 −0.01 と本州中部以西では弱い。

### Phase 7 — 北日本少雨、沖縄多雨

北日本 −0.33 mm/day、沖縄 +1.11 mm/day。気温では Phase 7 が「北日本冷」だったが、降水は北日本少雨・沖縄多雨のパターン。

### Phase 2, 5 — 弱信号

- Phase 2: japan +0.21、東西日本 +0.60 と多雨傾向だが北日本 −0.05 と弱い
- Phase 5: japan +0.32 と弱正、東西日本で差が大きく (東 +0.04、西 −0.02) 方向性に不安定さあり

## 6. lag 依存性 (JJA, japan ボックス)

| Phase | lag=0 | lag=+5 | lag=+10 |
|---|---:|---:|---:|
| 1 | −0.16 | −0.00 | −0.26 |
| 2 | +0.21 | +0.04 | +0.08 |
| 3 | −0.55 | −0.07 | −0.19 |
| 4 | **+0.61** | +0.29 | +0.27 |
| 5 | +0.32 | −0.00 | +0.33 |
| 6 | **−0.61** | −0.03 | +0.09 |
| 7 | +0.24 | +0.42 | +0.47 |
| 8 | **+1.06** | +0.19 | −0.10 |

- **Phase 8 の多雨は lag=0 でピーク、lag=+5 で急速に減衰** → MJO Phase 8 が来た「その日」が最も雨が多く、1 週間後にはほぼ消える。台風や前線活発化はほぼ同時対応的。
- **Phase 4 は lag=0 (+0.61) から lag=+5 (+0.29)、+10 (+0.27) と比較的持続**。
- **Phase 7 は lag=0 (+0.24) < lag=+5 (+0.42) < lag=+10 (+0.47) と遅延して増大**。Phase 7 の 10 日後 = Phase 8–1 への移行時に日本付近の降水が増える形で、位相進行のラグ応答。
- **Phase 6 の少雨は lag=0 のみ**で lag=+5 以降に消える。

## 7. 気温との比較

| Phase | t2m JJA lag=0 (japan, 1994–2023, amp≥0.5) | tp JJA lag=0 (japan, 1979–2023, amp≥1.0) |
|---|---|---|
| 1 | 涼 (−0.14 °C) | 少雨 (−0.16 mm/day) |
| 2 | 弱涼 (−0.07 °C) | 弱多雨 (+0.21) |
| **3** | **暑 (+0.46 °C)** | **少雨 (−0.55)** |
| 4 | 弱暑 (+0.12 °C) | **多雨 (+0.61)** |
| 5 | 中立 (+0.04 °C) | 弱多雨 (+0.32) |
| 6 | 弱暑 (+0.14 °C) | **少雨 (−0.61)** |
| **7** | **涼 (−0.21 °C)** | 弱多雨 (+0.24) |
| **8** | 弱涼 (−0.07 °C) | **強多雨 (+1.06)** |

降水と気温は必ずしも連動しない:

- **Phase 3**: t2m 暑 + 少雨 → **乾燥高温の典型**。太平洋高気圧強化・晴天卓越
- **Phase 8**: t2m 弱涼 + 多雨 → 降水システム (前線・台風) 活動が活発だが気温は上がらない
- **Phase 6**: t2m 弱暑 + 少雨 → Phase 3 ほど晴天卓越ではないが、降水抑制
- **Phase 7**: t2m 涼 + 弱多雨 → 北日本の涼冷はオホーツク高気圧系かもしれず、降水との不一致

### 8.3 各位相の ENSO 依存性

#### Phase 8 — 多雨シグナルは全 ENSO 層で安定

ALL / El Niño / La Niña / Neutral ともに正で符号が変わらない唯一の位相。La Niña でさらに強化 (+1.75 mm/day)。**降水における最も頑健な MJO シグナル**。

#### Phase 4 — El Niño 年で特に多雨

El Niño +0.85、Neutral +0.57 と全層で正。La Niña +0.34 は弱いが正を維持。El Niño 年の Phase 4 では西日本で +2.09 mm/day と突出して大きく、El Niño × 梅雨前線活発化との関連が示唆される。

#### Phase 6 — 少雨は全 ENSO 層で安定

El Niño −0.34、La Niña −0.80、Neutral −0.70 と全層で負。La Niña × Phase 6 では西日本が **−3.30 mm/day**（ただし n=28）、沖縄が +3.61 mm/day と南北で強い反位相。La Niña 夏の西日本少雨が MJO Phase 6 と重なると梅雨明け後の日照過多につながる可能性。

#### Phase 3 — Neutral 年のみ明瞭な少雨

ALL −0.55 は Neutral 年 −1.06 に引きずられた値で、El Niño / La Niña 年はほぼゼロ (±0.2 mm/day)。**「Phase 3 = 少雨」は Neutral 年限定**の信号で、全 ENSO 込みの値を ENSO 年に外挿するのは危険。

#### Phase 1 — ENSO で符号反転

El Niño −0.60 (少雨)、La Niña +0.36 (多雨) と逆符号。Neutral も −0.29。El Niño 年の Phase 1 では沖縄も −1.24 mm/day と広域少雨。

#### Phase 7 — ENSO 年で多雨、Neutral で中立

El Niño +0.57、La Niña +0.68 (n=19 で不確か) と ENSO 年では多雨傾向だが、Neutral −0.10 でほぼゼロ。全 ENSO 込みの +0.24 は El Niño / La Niña 年の寄与。La Niña × P7 の西日本 +2.61 mm/day は n=19 であり信頼性低。

#### Phase 2, 5 — 弱信号・ENSO 依存小

Phase 2 は全 ENSO 層で +0.16〜+0.31 と弱い正で安定。Phase 5 は El Niño / Neutral で弱正、La Niña でわずかに負と不安定。

## 9. 解釈上の注意

1. **振幅閾値の違い**: 本ドキュメントは amp≥1.0 (気温主要ランの amp≥0.5 より厳しい)。閾値を下げると信号が弱まりノイズが増えるため、比較する際は揃えることが理想。
2. **台風**: 台風の上陸は特定の MJO 位相と相関することが知られており (一般に Phase 5–8 で西太平洋台風が活発)、その寄与が本コンポジットの Phase 8 多雨に含まれている可能性がある。
3. **La Niña 小サンプル**: La Niña × Phase 5–7 は n < 30 で定量的な利用不可。方向性の参考に留める。
4. **t検定スティップリング**: 各マップには p<0.05 の有意格子に黒点を重ねて表示。ENSO 層別マップではサンプルが少ないため有意域が狭くなる。
